A Palm-inspired Classic Theme for native WordPress content, with a full-height left navigation rail and sliding secondary menu panels.

== Description ==

Palmy frames WordPress posts and pages as a desktop workspace. Assign a hierarchical menu to the Palmy sidebar menu location to control its primary and secondary navigation. The theme also provides native search, archive, category, comment, and pagination templates.

== Installation ==

1. Upload the Palmy theme ZIP in Appearance > Themes > Add New > Upload Theme, or copy the theme directory to wp-content/themes/palmy.
2. Activate Palmy.
3. Optionally assign a hierarchical menu to the Palmy sidebar menu location.
