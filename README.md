# Palmy

Palmy is an independent WordPress Classic Theme that presents native WordPress content inside a Palm-inspired desktop workspace. A wide left rail holds primary sections; parent sections open a full-height secondary panel. The gray device shell, pale green LCD, and tactile hardware controls carry the visual language into a practical publishing interface.

## First release scope

- Native WordPress posts, pages, categories, search, archives, comments, and pagination.
- A registered `Palmy sidebar menu` location. Parent and child menu items become the primary rail and sliding secondary panel; without an assigned menu, sensible links are generated from published pages and categories.
- Responsive navigation: a drawer on small screens and a sliding panel for secondary links.
- Header actions for search, sign-in/new post, and account links. Footer hardware controls for Back, scroll, Home, and Notes.
- No companion plugin, custom post type, or remote service is required.

## Install

Download the latest install ZIP from [GitHub Releases](https://github.com/wp-im/palmy/releases), then upload it in **Appearance → Themes → Add New → Upload Theme**. On a Multisite network, a network administrator must install the theme first; a site administrator can then activate it for the intended site. Optionally assign a hierarchical menu to **Palmy sidebar menu** under **Appearance → Menus → Manage Locations**.

Requirements: WordPress 6.1 or newer and PHP 7.4 or newer.

## Release

The repository contains the theme source. Each tagged release provides a ready-to-install theme ZIP.
